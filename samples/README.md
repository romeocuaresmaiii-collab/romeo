# Production pack sample

`production-pack-reversible-singlet.txt` is the team's reference for what "Copy full brief for AI"
should produce: title block, Read this first, Parts 1–7 (verified and missing, shot list, product
photos + motion, editor prompt with timeline and house style, voice-over, caption, review checklist).
The brief built by `aiBrief()` in `index.html` asks the AI for this layout.
